📈 Sales Dashboard Using Microsoft Excel

📌 Project Overview
The Sales Dashboard is a data analytics project built using Microsoft Excel to explore sales performance and present business data through charts, summary calculations, and visual reports.
The dashboard helps analyse sales trends, compare performance across products and regions, and understand revenue and profitability.

✨ Features
💰 Sales and revenue analysis
📊 Profit and profitability tracking
📅 Monthly and time-based sales trends
🌍 Regional sales comparison
🛒 Product and category performance analysis
📉 Visual summaries for business insights

🛠️ Tools & Technologies
Microsoft Excel
PivotTables and charts
Excel formulas and functions
Data organisation and cleaning
Sales data analysis
Data visualisation

🚀 How to Use
Clone or download this repository.
Open Sales_Dashboard.xlsx in Microsoft Excel.
Navigate to the dashboard worksheet.
Explore the charts, tables, and available filters.
Review the sales information to identify trends and performance patterns.
